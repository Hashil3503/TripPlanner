내 여행

    여행 일정을 만들어 볼까요?

    지도에서 장소를 고르고 일정을 짜면 이동 시간·교통비를 자동으로 계산해요.

    1. 1여행 이름과 날짜를 정해요
    2. 2장소를 검색하거나 지도를 눌러 일정에 담아요
    3. 3이동수단별 시간과 비용을 한눈에 확인해요

    로그인하면 만든 여행이 계정에 저장돼요.

    지도를 클릭해도 그 지점을 일정에 추가할 수 있어요.

        아직 일정이 없어요.
        위에서 장소를 검색하거나 지도를 클릭해 추가해 보세요.

        지도 © Kakao · 경로 OSRM(FOSSGIS) · 대중교통 카카오맵 · 택시 요금은 추정치입니다.

        새 여행

        여행 기간은 최대 30일까지 정할 수 있어요.

        이동 시간·요금 직접 입력

        비워 두면 자동 계산값을 써요. 이동수단을 바꾸거나 순서를 바꾸면 직접 입력한 값은 지워져요.

        일정 수정

        시작·종료·체류 중 두 개를 정하면 나머지는 자동으로 계산해요.

        주차비는 이 장소까지 자가용으로 이동할 때만 반영됩니다.

        설정

        화면 테마

        바로 적용되고 이 브라우저에 저장돼요. 시스템을 고르면 기기 설정을 따라가요.

        지도 · 장소 검색 (카카오)

        카카오 키는 서버를 실행하는 PC의 환경변수 TP_KAKAO_JS_KEY(지도·검색)와 TP_KAKAO_REST_KEY(대중교통)로 설정해요. start.bat을 실행하면 비어 있는 키를 입력받아 등록해 줘요. 키를 바꾼 뒤에는 서버를 다시 시작하세요.

        요금 기준의 기본값은 서울 2025년 교통카드/중형택시입니다. 지역이나 상황에 맞게 바꿔 보세요.

        로그인

        아이디는 3~20자(영문, 숫자, 밑줄), 비밀번호는 8~72자예요.

        비밀번호 변경

        비밀번호는 8~72자예요. 변경하면 다른 기기에서는 로그아웃돼요.

        회원 탈퇴

        탈퇴하면 계정과 서버에 저장된 모든 여행이 영구적으로 삭제되고, 복구할 수 없어요.

        필요한 여행은 먼저 여행 목록에서 JSON 내보내기로 저장해 두세요.

        여행이 먼저 수정됐어요

        다른 곳의 버전을 불러오면 이 기기의 변경은 사라지고, 덮어쓰면 다른 곳의 변경이 사라져요.
