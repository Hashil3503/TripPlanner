# 🧭 여행 플래너

카카오 지도를 보면서 동선을 짜고, 일정을 등록하면 **이동 거리 · 소요 시간 · 교통비**를 자동으로 계산해 주는 웹 앱입니다.
로컬 서버(Node.js)가 화면을 제공하고, **회원가입/로그인하면 여행이 계정에 저장**됩니다. 로그인하지 않아도(게스트) 예전처럼 브라우저에 저장하며 그대로 쓸 수 있습니다.
외부 패키지(npm install)는 필요 없습니다.

## 실행 방법

1. [Node.js](https://nodejs.org) **22.13 이상**(권장 24)을 설치합니다. (내장 `node:sqlite`를 사용합니다.)
2. 지도를 쓰려면 **카카오 JavaScript 키**를, 실제 대중교통 경로/요금을 쓰려면 **카카오 REST API 키**를 넣습니다 (아래 "카카오 지도 키 설정", "카카오 REST API 키 설정(대중교통)").
3. **`start.bat`을 더블클릭**하면 서버가 켜지고 브라우저가 `http://localhost:8000`으로 열립니다.
   - 직접 실행: `node server.js` 또는 `npm start` 후 `http://localhost:8000`
   - 종료: 서버 창을 닫거나 `Ctrl+C`
4. 포트 8000이 이미 사용 중이면 서버가 안내 메시지를 내고 종료합니다. 카카오 키에 `http://localhost:8000`을 등록했기 때문에 포트는 8000으로 고정입니다.

- 드래그 정렬(SortableJS), 글꼴, 카카오 지도, 검색/경로 API는 인터넷 연결이 필요합니다.
- 첫 실행 시(게스트) "서울 1박 2일" 샘플 여행이 자동으로 로드됩니다.
- `index.html`을 직접 열면(file://) 서버 API가 없어 로그인할 수 없고, 카카오 도메인 검증도 실패합니다. 반드시 `http://localhost:8000`으로 여세요.

## 계정 기능

- 상단의 **로그인 / 회원가입**으로 계정을 만듭니다. 아이디는 3~20자(영문, 숫자, 밑줄), 비밀번호는 8~72자입니다. 아이디는 대소문자를 구분하지 않고 중복 가입이 안 됩니다.
- **게스트 모드**(로그아웃 상태): 예전과 똑같이 브라우저 `localStorage`에 저장합니다. 화면 위에 "로그인하면 일정이 계정에 저장됩니다" 안내가 표시됩니다(× 로 숨길 수 있음).
- **로그인/가입 직후**: 서버의 여행을 불러옵니다. 이 기기(게스트)에 서버에 없는 여행이 있으면(손대지 않은 샘플은 제외) "이 기기에 있는 여행 N개를 계정으로 가져올까요?"라고 묻고, 확인하면 계정으로 올립니다. 새 계정이면 이 기기의 설정(인원, 요금 기준)도 계정 기본값으로 가져옵니다. 게스트 데이터는 기기에 그대로 남습니다.
- **로그인 상태**: 서버가 원본입니다. 여행을 바꾸면 약 0.8초 뒤 자동 저장되고 상단에 "저장 중… / 저장됨 / 저장 실패 - 다시 시도" 상태가 표시됩니다(실패 표시를 누르면 재시도). 여행 삭제와 설정(요금 기준, 인원) 변경도 서버에 반영됩니다. 빠른 새로고침을 위해 사용자별 `localStorage` 캐시를 두지만, 페이지를 열 때마다 서버에서 다시 불러옵니다.
- **로그아웃**: 메모리의 계정 데이터를 지우고 게스트 데이터로 돌아갑니다. 세션은 30일 동안 유지됩니다.
- JSON **내보내기/가져오기**는 그대로 동작하며, 로그인 상태에서 가져오면 서버에 저장됩니다.
- 카카오 키(설정 창에 입력한 값)는 계정에 저장하지 않고 이 브라우저에만 저장합니다.

## 주요 기능

- **여행 관리**: 여행 생성/수정/삭제(이름, 출발 날짜, 일수), 일차 탭, 일 추가/삭제. JSON 내보내기/가져오기 지원.
- **지도(카카오맵)**: 일정 번호 마커(일차별 색상), 구간별 경로선(도로 경로는 실선, 대중교통 실경로는 버스/지하철 구간 실선 + 도보·환승 구간 점선, 대중교통 추정/조회 실패는 긴 점선), 마커 클릭 시 정보 말풍선, 일정 클릭 시 해당 마커로 이동, 일차 변경 시 자동 맞춤, "전체 일차 지도 표시" 옵션, 일반/스카이뷰 전환, 확대/축소 컨트롤.
- **장소 추가**: 검색창(입력 후 디바운스: 카카오 0.3초 / OSM 0.7초) 결과에서 "일정에 추가" (결과마다 "카카오"/"OSM" 출처 태그 표시), 또는 지도를 클릭하면 역지오코딩된 이름으로 추가.
- **일정 항목**: 이름/좌표/카테고리(관광·식사·숙소·카페·쇼핑·기타)/체류시간/메모/입장료·기타 비용/주차비, 드래그로 순서 변경(자동 재계산).
- **구간 자동 계산**: 이동수단(도보·자전거·대중교통·택시·자가용)별 거리/시간/비용. 대중교통은 카카오맵 실제 경로·소요 시간·요금을 쓰고(REST 키 필요), 조회가 안 되면 추정값으로 대체합니다. 첫 장소의 시작 시각부터 `도착 = 이전 출발 + 이동시간`, `출발 = 도착 + 체류시간`으로 연쇄 계산하고, 자정을 넘기면 경고합니다. 기본 이동수단은 직선거리 1.2km 이하 도보, 그 외 대중교통이며 구간마다 바꿀 수 있습니다.
- **대중교통 실경로**: 구간 카드에 "🚇 5호선 → 🚌 7212 · 환승 1회", 소요 시간, 요금(× 인원)이 표시되고, 드롭다운에서 대안 경로(예: "버스 33분 1,500원" / "지하철 32분 1,550원", 최대 5개)를 고를 수 있습니다. 기본값은 가장 빠른 경로이며, 고른 번호는 여행 데이터(`transitIdx`)에 저장됩니다(로그인 시 서버에 저장). "카카오맵에서 보기" 링크로 카카오맵 길찾기를 엽니다.
- **요약**: 일차별/전체 이동 시간·거리·교통비·입장료·합계, 1인당 금액, 이동수단별 비용 막대 그래프.
- **설정(⚙)**: 모든 요금 상수와 추정 파라미터를 수정할 수 있고 저장됩니다. 인원은 패널의 "인원" 입력에서도 바꿀 수 있습니다.

## 데이터는 어디에 저장되나요

| 상태 | 위치 |
| --- | --- |
| 로그인 (계정, 여행, 설정) | **`data/tripplanner.db`** (SQLite 파일, 서버가 처음 실행될 때 자동 생성). 이 파일을 복사해 두면 백업됩니다. `.gitignore`에 들어 있어 커밋되지 않습니다. |
| 게스트 | 브라우저 `localStorage` (`tripplanner.state.v1`) |
| 로그인 사용자 캐시 | 브라우저 `localStorage` (`tripplanner.state.v1.user.<소문자 아이디>`) — 서버 데이터가 우선, 로그아웃·세션 만료 시 삭제 |
| 경로 조회 캐시(대중교통 포함, `tripplanner.routecache.v2`), 카카오 JavaScript 키(설정 창 입력값) | 브라우저 `localStorage` |
| 카카오 REST API 키 | 서버의 **`config.local.json`**(`.gitignore` 대상) 또는 환경변수 `KAKAO_REST_KEY`. 브라우저로는 절대 전달되지 않습니다. |
| 대중교통 조회 캐시 | `data/tripplanner.db`의 `transit_cache` 테이블 (성공 7일, 경로 없음 1일) |

DB 테이블: `users`(아이디, 비밀번호 해시, 설정 JSON), `sessions`(세션 토큰의 SHA-256, 만료 시각), `trips`(여행 JSON, 사용자별), `transit_cache`(카카오 대중교통 응답 캐시, 사용자와 무관). 모든 여행 쿼리는 로그인한 사용자의 `user_id`로 제한됩니다.

## 보안 메모

- 서버는 **`127.0.0.1`에만 바인딩**하므로 같은 컴퓨터에서만 접속할 수 있습니다. 다른 기기에서 쓰려면 별도의 HTTPS/리버스 프록시 등 추가 보안이 필요하며, 이 프로젝트는 그런 공개 배포를 전제로 하지 않습니다.
- 비밀번호는 **scrypt**(무작위 16바이트 솔트)로 해시해 `scrypt$솔트$해시` 형태로만 저장하고 `timingSafeEqual`로 비교합니다. 원문은 저장하지 않습니다.
- 세션은 무작위 32바이트 토큰을 `HttpOnly; SameSite=Lax` 쿠키(30일)로 보내며, DB에는 토큰의 SHA-256만 저장합니다.
- 로그인 실패는 IP+아이디당 15분에 10회까지 허용하고(메모리 기준, 서버 재시작 시 초기화), 오류 메시지는 "아이디 또는 비밀번호가 올바르지 않습니다"로 통일합니다.
- 상태를 바꾸는 요청(POST/PUT/DELETE)은 `Content-Type: application/json`이 필수이고, `Origin` 헤더가 있으면 `http://localhost:8000`(또는 `127.0.0.1:8000`)이어야 합니다. `Host` 헤더도 확인합니다(DNS 리바인딩 방어). 요청 본문은 1MB로 제한합니다.
- 정적 파일은 `public/` 아래만 제공하고(경로 이탈 차단, 숨김 파일 차단, 디렉터리 목록 없음), `server.js`, `server/`, `data/`는 웹에서 접근할 수 없습니다.
- 사용자 입력 텍스트는 `textContent`/DOM API로만 화면에 넣어 XSS를 방지합니다.
- **카카오 REST API 키는 서버에서만 사용**합니다. 브라우저는 `/api/transit`(좌표만 전달)을 호출하고, 응답과 오류 메시지 어디에도 키가 포함되지 않습니다. 대중교통 조회는 카카오 호출(캐시 미스) 기준 IP당 분당 60회로 제한하고, 카카오 응답은 10초 안에 오지 않으면 포기합니다.
- 카카오 JavaScript 키는 브라우저에 노출되는 값입니다. 카카오 개발자 콘솔에서 등록한 도메인(`http://localhost:8000`)에서만 동작합니다.

## API 요약

모두 JSON이며, 상태 변경 요청에는 `Content-Type: application/json`이 필요합니다.

| 메서드/경로 | 설명 |
| --- | --- |
| `POST /api/signup` `{username,password}` | 가입 + 즉시 로그인 |
| `POST /api/login` `{username,password}` | 로그인 (`{username, settings}` 반환) |
| `POST /api/logout` | 로그아웃 |
| `GET /api/me` | 현재 사용자 `{username, settings}` 또는 401 |
| `GET /api/trips` | 내 여행 전체 `{trips:[...]}` |
| `PUT /api/trips/:id` `{trip}` | 여행 저장(없으면 생성, 있으면 덮어쓰기) |
| `DELETE /api/trips/:id` | 여행 삭제 |
| `PUT /api/settings` `{settings}` | 요금/인원 등 설정 저장 |
| `GET /api/transit?sx=&sy=&ex=&ey=` | 카카오 대중교통 길찾기 프록시 (경도 `x`, 위도 `y`; 로그인 불필요). 200 `{status:'OK'|'NO_RESULTS', landingURL, routes:[{type, totalDistance, totalTime, transfers, fare, steps:[{type, guidance, distance, time, vehicles, stopCount, firstStop, lastStop, path:[[lat,lon],...]}]}]}` (경로 최대 5개, `totalTime` 초·`totalDistance` m). 400 잘못된 좌표, 429 호출 한도, 502/504 카카오 오류·지연, 503 REST 키 미설정. 응답 헤더 `X-Transit-Cache: HIT/MISS` |

## 데이터 출처

| 용도 | 서비스 | 비고 |
| --- | --- | --- |
| 지도 | 카카오맵 JavaScript SDK | 키가 없거나 로드에 실패하면 지도 영역에 설정 방법 안내가 표시되고 나머지 기능은 그대로 동작 |
| 장소 검색/역지오코딩 (1순위) | 카카오 SDK `services` 라이브러리 | 키워드 검색 -> 주소 검색 순 |
| 장소 검색/역지오코딩 (대체) | Nominatim (`nominatim.openstreetmap.org`) | 카카오를 쓸 수 없거나 결과가 없을 때(해외 등). 사용 정책에 따라 초당 1회 이하로 호출(요청 큐로 간격 유지) |
| 도보/자전거/자동차 경로 | OSRM (FOSSGIS: `routing.openstreetmap.de`) | `routed-foot`, `routed-bike`, `routed-car` 프로필 |
| 대중교통 경로·소요 시간·요금 | 카카오맵 대중교통 길찾기 REST API (`dapi.kakao.com/v2/routing/publictraffic`) | 서버가 REST 키로 대신 호출하고 정규화해 캐시. 요금은 교통카드 성인 1인 기준(인원수 곱함). 소요 시간은 정류장까지 도보 포함 |

경로 결과는 메모리와 `localStorage`에 좌표+이동수단 기준으로 캐시합니다(대중교통은 저장 용량 상한을 넘으면 오래된 것부터 버립니다). 경로 조회가 실패하면 **직선거리 x 1.3(우회 계수)** 와 이동수단별 평균 속도로 추정하고, 해당 구간에 "추정(직선거리 기반)" 표시가 붙습니다(상단 "경로 다시 계산"으로 재시도).

## 카카오 지도 키 설정

지도와 장소 검색에 카카오 지도 JavaScript SDK를 사용합니다. 키는 무료로 발급받을 수 있습니다.

1. [Kakao Developers](https://developers.kakao.com)에서 **애플리케이션을 추가**합니다.
2. 앱 > **앱 키**에서 **JavaScript 키**를 복사합니다.
3. 앱 > **플랫폼 > Web(JavaScript SDK 도메인)** 에 사이트 도메인 **`http://localhost:8000`** 을 등록합니다. (다른 포트/주소로 열면 등록한 도메인과 달라 인증에 실패합니다.)
4. 앱 설정에서 **카카오맵**을 활성화(사용 설정)합니다.
5. 키를 다음 중 한 곳에 넣습니다.
   - **`public/js/config.local.js`** (권장): `public/js/config.local.example.js`를 `public/js/config.local.js`로 복사하고 `window.TP_CONFIG = { kakaoJsKey: '여기에 키' };`로 수정합니다. 이 파일은 `.gitignore`에 들어 있어 커밋되지 않습니다.
   - **설정(⚙) > "카카오 JavaScript 키"** 입력란: 브라우저 `localStorage`에 저장되며 `config.local.js`보다 우선합니다. (JSON 내보내기와 계정에는 포함되지 않습니다.) 키를 바꾸면 **페이지를 새로고침**해야 적용됩니다.

동작 방식과 대체(fallback):

- SDK는 `js/kakao.js`의 공유 로더가 `https://dapi.kakao.com/v2/maps/sdk.js?...&libraries=services&autoload=false`를 한 번만 불러오며, 지도(`map.js`)와 검색(`geocode.js`)이 함께 사용합니다.
- 키가 없거나 SDK 로드에 실패하면(잘못된 키/도메인 미등록/카카오맵 미활성화/네트워크 오류, 8초 시간 초과) 지도 영역에 원인과 설정 방법이 표시됩니다. 일정 편집, 비용 계산, 저장은 그대로 쓸 수 있고 장소 검색은 Nominatim으로 대체됩니다. 설정 창에서 현재 상태(사용 중/실패 사유)를 확인할 수 있습니다.
- 검색: 카카오 **키워드 검색**(최대 10건) -> 결과가 없으면 카카오 **주소 검색** -> 그래도 없으면(해외 등) **Nominatim**. 카카오 카테고리는 앱 카테고리(음식점 -> 식사, 카페, 숙박 -> 숙소, 관광명소·문화시설 -> 관광, 대형마트·편의점 -> 쇼핑, 그 외 기타)로 매핑합니다.
- 지도 클릭 역지오코딩: 카카오 `coord2Address`로 건물명 > 도로명주소 > 지번주소 순으로 이름을 채우고, 실패하거나 결과가 없으면 Nominatim을 사용합니다.
- 다크 모드에서도 지도 타일은 어둡게 바꾸지 않고 그대로 표시합니다(마커/말풍선만 읽기 쉽게 유지).

## 카카오 REST API 키 설정(대중교통)

실제 대중교통 경로·시간·요금은 카카오맵 대중교통 길찾기 REST API로 조회합니다. 키는 서버에만 두고 브라우저로 보내지 않습니다.

1. [Kakao Developers](https://developers.kakao.com) > 내 애플리케이션 > **앱 설정 > 앱 > 플랫폼 키 > REST API 키**를 복사합니다. (`호출 허용 IP`는 비워 둬도 됩니다.) 카카오맵 사용 설정이 되어 있어야 합니다.
2. `config.local.example.json`을 **`config.local.json`** 으로 복사하고 키를 넣습니다. (`.gitignore` 대상이라 커밋되지 않습니다.)
   ```json
   { "kakaoRestKey": "여기에 REST API 키" }
   ```
   또는 환경변수 `KAKAO_REST_KEY`로 지정합니다(설정 파일보다 우선). 서버 실행 중에 파일을 새로 만들어도 몇 초 안에 적용됩니다.
3. 조회 결과는 SQLite에 캐시되므로 같은 구간(좌표 소수 5자리 기준)은 7일 동안 카카오를 다시 호출하지 않습니다.

대체(fallback) 동작:

- 키가 없거나(503), 카카오 오류/한도 초과/시간 초과가 나거나, 경로가 없으면(도시 간 이동, 너무 가까운 거리, 해외 등) 해당 구간은 **추정값**(자동차 도로 거리 기반)으로 계산하고 카드에 "대중교통 추정"과 사유를 표시합니다. 경로 없음은 "대중교통 경로 없음(도시 간 이동·너무 가까운 거리 등)"으로 표시됩니다.
- 버스 요금이 하나로 오지 않는 경로(범위로만 오는 경우)는 요금을 거리 기준으로 추정하고 "요금 추정" 표시가 붙습니다.
- 설정(⚙)의 대중교통 요금/속도 값은 이런 **추정 경우에만** 쓰입니다.

## 요금/시간 추정 가정

모든 값은 `public/js/fare.js` 상단의 `DEFAULT_CONFIG`에 있고 설정 창에서 바꿀 수 있습니다.

- **대중교통(추정 — 카카오 조회 실패 시에만)**: 자동차 도로 거리로 추정합니다. 시간 = 거리 / 22km/h + 10분(대기·환승·도보). 요금(서울 수도권 2025, 교통카드 기준): 10km까지 1,550원, 10~50km는 5km마다 +100원(올림), 50km 초과분은 8km마다 +100원. 인원수만큼 곱합니다. 실제 노선, 환승 할인, 지역별 요금 차이는 반영하지 않습니다.
- **택시(서울 중형)**: 기본 1.6km 4,800원, 이후 131m마다 100원. 출발 시각 기준 심야할증 22~23시·02~04시 20%, 23~02시 40%(100원 단위 반올림). 저속 주행 시간요금과 호출료는 반영하지 않습니다. 소요 시간은 OSRM 자동차 경로(교통 체증 미반영) 기준입니다. 요금은 차량 1대를 인원이 나눠 낸다고 가정하며 총액과 1인당 금액을 함께 표시합니다.
- **자가용**: 연료비 = 거리 / 연비(12km/L) x 유가(1,700원/L) + 장소별로 입력한 주차비(해당 장소까지 자가용으로 이동한 경우에만 반영). **통행료(고속도로)는 계산하지 않습니다.**
- **도보/자전거**: 0원.
- 입장료/기타 비용은 **1인 기준**으로 입력하며 인원수를 곱해 합산합니다.

## 알려진 한계

- 대중교통은 카카오 REST 키가 없거나 조회에 실패하면 추정치입니다. 실제 경로 조회도 출발 시각(실시간 배차)은 반영하지 않으며, 환승 할인·지역별 요금 차이는 카카오가 준 요금을 그대로 씁니다.
- OSRM 공개 서버는 공정 사용 정책이 있고 응답이 느리거나 실패할 수 있습니다(이 경우 추정값으로 대체).
- 실시간 교통 상황, 통행료, 택시 시간요금은 반영하지 않습니다.
- 비밀번호 재설정 기능은 없습니다(로컬 전용 앱). 비밀번호를 잊으면 `data/tripplanner.db`를 지우고 새로 가입해야 합니다. 여행 JSON을 미리 내보내 두세요.
- 같은 계정을 여러 탭/기기에서 동시에 편집하면 마지막에 저장한 내용이 우선합니다(충돌 병합 없음).
